⚖️ Reglas Minecraft

AVISO: El equipo de moderación tiene plena autoridad para sancionar cualquier conducta que considere inapropiada, aunque no aparezca expresamente en este reglamento.

➤ Leer las normas es algo obligatorio. No ser consciente de ellas no justifica su incumplimiento.

1.

No está permitido estafar a otros jugadores bajo ninguna circunstancia.

2.

Prohibido el tpakill (teletransportar a alguien para asesinarlo).

3.

Prohibido el uso de hacks, clientes modificados o cualquier elemento que otorgue una ventaja injusta.

4.

Uso estrictamente prohibido de Xray y Killaura.

5.

No se permite griffear (destruir o robar) construcciones ajenas o el mapa del servidor.

6.

Prohibido utilizar skins obscenas o inapropiadas para el ambiente del servidor.

7.

No intentar evadir una sanción mediante el uso de multicuentas o servicios de VPN.

8.

Prohibido aprovecharse de bugs o errores técnicos para beneficio propio o de terceros.

9.

No está permitido filtrar información privada (Doxing) de un jugador o de uno mismo.

10.

No utilizar nombres (nicks) que contengan insultos o sean considerados obscenos.

11.

Uso adecuado de los comandos: prohibido mandar /report falsos o utilizarlos para insultar.

Juega con honor en Kubeon Network.
