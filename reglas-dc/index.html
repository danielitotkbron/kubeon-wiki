💬 Reglas Discord

AVISO: El equipo de moderación tiene plena autoridad para sancionar cualquier conducta que considere inapropiada, aunque no aparezca expresamente en este reglamento.

➤ Leer las normas es algo obligatorio. No ser consciente de ellas no justifica su incumplimiento.

➤ Esta lista solo incluye las normas más destacables para facilitar su lectura.

➤ Las reglas se aplican al servidor y mensajes directos.

Reglas Generales

1. No Se Permite Insultar, molestar, discriminar o faltar el respeto a los usuarios.
2. Prohibido contener nombres o avatares inapropiados (símbolos nazis, fotos explícitas, etc.)
3. No Está Permitido utilizar nombres intagueables.
4. Prohibido cualquier tipo de spam (redes sociales, otros servidores, etc.) dentro y fuera del servidor.
5. No está permitido publicar contenido delicado, NSFW o +18.
6. No se tolerará el acoso, hostigamiento o la toxicidad a usuarios o staffs.
7. Esta prohibido evadir sanciones mediante el uso de multicuentas.

Reglas Canales de Voz

1. Saturación, gritos, soplos o poner música a través del micrófono para molestar.
2. El uso de modulador de voz, SoundPad y apps similares para molestar.
3. Trasmitir chats privados de cualquier red social.
4. Trasmitir apps como: OmeTV, Tinder; o contenido con copyright (Netflix, HBO, etc.)
5. Trasmitir contenido NSFW o mostrar elementos ilegales mediante la cámara.
