💬 Reglas Discord

> Leer las normas es algo obligatorio. No ser consciente de ellas no justifica su incumplimiento.

> Las reglas se aplican al servidor y mensajes directos.

> El equipo de moderación está facultado para sancionar cualquier conducta no listada si se considera inapropiada.

Reglas Generales

1. No se permite insultar, molestar o discriminar a otros usuarios.

2. Prohibido usar nombres o avatares inapropiados (NSFW, símbolos prohibidos, etc).

3. Prohibidos los nombres intagueables.

4. No está permitido el spam o publicidad de otros servidores.

5. No publicar contenido malicioso, NSFW o +18.

6. No se tolera el acoso o toxicidad hacia miembros o Staff.

7. Prohibido evadir sanciones mediante multicuentas.

Reglas Canales de Voz

1. Prohibido gritar, soplar o poner sonidos molestos por el micrófono.

2. Prohibido el uso de moduladores de voz o SoundPads para molestar.

3. Prohibido transmitir chats privados.

4. Prohibido transmitir OmeTV, Tinder o contenido con copyright (Netflix, HBO, etc).

5. Prohibido transmitir contenido NSFW o ilegal por cámara.

🍃 INFO EXTRA

🌿 Reporta cualquier incidente mencionando a un AYUDANTE o abriendo un ticket.

🌿 Si sufres acoso, repórtalo de inmediato con capturas de pantalla como prueba.
