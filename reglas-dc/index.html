💬 Reglas Discord

AVISO: El equipo de moderación tiene plena autoridad para sancionar cualquier conducta que considere inapropiada, aunque no aparezca expresamente en este reglamento. Esto garantiza que todos podamos jugar de manera justa, segura y divertida.

𝄀 𝅍 Leer las normas es algo obligatorio. No ser consciente de ellas no justifica su incumplimiento.

Reglas Generales

1. No Se Permite Insultar, molestar, discriminar, faltar el respeto a los usuarios.
2. No Está Permitido Contener nombre y/o avatar inapropiado (símbolos nazis, foto explícitas, etc.)
3. No Está Permitido Contener nombres intagueables.
4. No Está Permitido cualquier tipo de spam (redes sociales, servidores de Discord, Minecraft, etc.) dentro y fuera del servidor.
5. No esta permitido publicar contenido delicado, sugestivo, malicioso, NSFW o +18.
6. No se va a tolerar el acoso, el hostigamiento o la toxicidad a usuarios o staffs.
7. Esta prohibido evadir sanciones mediante el uso de multicuentas.

Reglas Canales de Voz

1. Saturación, gritos, soplos o poner música a través del micrófono con el fin de molestar.
2. El uso de modulador de voz, SoundPad y aplicaciones similares para molestar.
3. Trasmitir chats privados de cualquier red social.
4. Trasmitir aplicaciones como: OmeTV, Tinder; contenido con derechos de autor (Netflix, Prime Video, HBO, etc.)
5. Trasmitir contenido NSFW o mostrar elementos ilegales mediante la cámara.
